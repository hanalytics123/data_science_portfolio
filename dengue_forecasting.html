Predicting Dengue Cases Using Climate and Environmental Data

A one-week-ahead forecasting project using public dengue surveillance, climate and environmental data.

Project Summary

This project investigates whether climate and environmental variables can improve short-term dengue case forecasting for Maynas, Loreto, Peru. Historical dengue surveillance data was combined with rainfall, temperature, humidity, wind, pressure and vegetation indicators to create a weekly modelling dataset.

The final modelling task was framed as a one-week-ahead regression problem. Information available up to week t-1 was used to predict dengue cases in week t, helping prevent leakage from the target week into the model inputs.

Research Questions

  • Can weekly dengue cases be forecast one week ahead using historical dengue incidence?
  • Do climate and environmental variables improve prediction beyond dengue history and seasonality?
  • Which modelling approach provides the most accurate forecasts?
  • Do machine-learning approaches outperform traditional time-series methods?

Methods

  • Data cleaning, integration and quality checks
  • Exploratory data analysis and visualisation
  • Lagged and rolling feature engineering
  • Chronological train, validation and final-test split
  • Model comparison using MAE, RMSE and R²
  • Feature importance and higher-incidence week error analysis

Models Compared

Persistence Previous week's cases 11.22 22.00 0.844
XGBoost History only 11.45 22.35 0.839
SARIMA History + seasonality 12.14 21.67 0.849

Key Findings

  • The climate-enhanced XGBoost model achieved the best final holdout performance.
  • Recent dengue incidence was the strongest predictor of one-week-ahead dengue cases.
  • Climate and environmental variables provided a modest improvement over the equivalent history-only XGBoost model.
  • Higher-incidence weeks remained harder to forecast, but the climate-enhanced XGBoost model performed best for this subgroup.
  • The final evaluation showed why an untouched future holdout is important, as validation results did not perfectly match final-test performance.
